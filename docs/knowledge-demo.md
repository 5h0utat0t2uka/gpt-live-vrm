# 国立国会図書館FAQデモ

「知識」パネルで会話開始前に参照先を選択します。

- 未選択：従来の一般会話・Web検索。
- 選択あり：選択したFAQだけに基づく回答。Web検索ツールは登録しません。
- 会話中（接続・終了処理を含む）は選択を変更できません。終了後に変更して新しい会話を開始します。
- 質問と同じ言語で回答します（英語の質問には英語、中国語の質問には中国語）。回答言語を明示された場合はその指定を優先します。日本語のFAQは内容に忠実に訳して回答します。
- FAQに情報がなければ「選択されたFAQには記載がありません」という意味を回答言語で伝えるよう指示しています。これはモデルへの指示であり、生成文の根拠をプログラムで完全に保証するものではありません。

## データと出典

本文は `src/data/knowledge/ndl-faq.json` に保存しています。`public/` には配置せず、`knowledge-server.ts` からサーバー上で読み込みます。ブラウザに共有する一覧は `knowledge-catalog.ts` のID・表示名・説明・出典情報だけです。取得した本文はツール結果を中継する際にブラウザのメモリを通ります。秘密情報向けの保管・アクセス制御としては扱わないでください。

## 処理の流れ

1. `/api/session` が選択IDを許可リストで検証し、選択ありの場合は `read_selected_faq` 関数を登録します。モデル、プロンプト、ツールをリクエストから指定することはできません。
2. GPT-LiveがResponsesへ委譲し、`response.event` 内の `response.output_item.done` に届く関数呼び出しを処理します。
3. `/api/knowledge` へ会話開始時の選択IDを送ります。モデルがID・ファイル名・URLを指定することはできません。APIはBasic認証・同一Origin・JSON・本文サイズ・IDを検証して該当するFAQだけを返します。
4. 少量のサンプルなので選択グループの全文を返し、モデルが該当FAQを選びます。ベクトルDBや外部ストアは使用しません。
5. `response.completed` とその応答に属する全関数結果を待って、`response.item.create` で結果を返し、`response.create` を一度送って再開します。終了・中断後の結果は再開に使用しません。
6. 「参照」には取得したFAQの出典を表示します。これは取得記録であり、すべてのFAQを回答に引用したという表示ではありません。Web検索の引用とは分けています。

選択は参照範囲の指定です。認証済み利用者は任意の公開FAQグループを選択できます。利用者ごとに閲覧権限の異なる社内資料を追加する場合は、別途サーバー側の認可が必要です。

公式仕様： https://developers.openai.com/api/docs/guides/live-delegation#run-a-custom-function-and-return-its-result

## 動作確認

- 「利用案内」だけを選択：「入館や登録に料金はかかりますか？」→無料、複写は有料。「参照」に利用案内の取得記録。
- 同じ選択：「コピーを拡大できますか？」→選択されたFAQには記載がないと伝える。
- 会話を終了し「資料の閲覧・複写」を選択：「コピーを拡大できますか？」→個別の拡大・縮小には対応しないと回答。
- 複数選択でそれぞれの範囲の質問に回答する。
- 「明日の天気は？」→FAQ選択中は範囲外。未選択の新しい会話ではWeb検索を利用する。
- FAQ回答中に割り込む、参照中に終了する、再接続する。前の会話の結果が混入しないことを確認する。

`pnpm test` は課金なしのモックで認証・選択の検証・関数呼び出し・複数結果・重複・失敗・終了処理を確認します。実際の委譲判断、回答の正確性、発話・割り込みは、実APIを利用した音声確認で別途評価してください。
